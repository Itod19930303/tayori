# tayori
家族間での動画・画像共有するアプリ

このプロジェクトは [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) でブートストラップされた [Next.js](https://nextjs.org) プロジェクトです。

## Getting Started

開発サーバーを起動する:

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) にアクセスして表示を確認する。

`src/app/page.tsx` を編集するとページが自動更新される。
